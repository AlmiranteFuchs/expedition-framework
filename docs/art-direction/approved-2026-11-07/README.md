The earlier B choices for Dormant Bloom and Return Knot are the style reference.
The palette is pale bark, warm gray grain, dark brown recesses and sparse amber.
Workshop columns compare carved, assembled and grown construction.

Generated with the built-in image-generation tool using the approved B
concept sheet as a material and palette reference. Prompt subjects cover
the twelve materials candidates, twelve equipment candidates, and nine
world/workshop candidates shown on the boards.

## Implementation

The selected inventory candidates are authored as native 16x16 pixel sprites
in tools/item_art.py. native-items.png shows enlarged and actual-size copies.
W1A and W2A are native models generated by tools/approved_workshop_art.py,
with exposed-face meshes. Machine collision is derived from its model body.
The arch's top posts turn their carved shoulders toward the collar.
W3C uses nine-sliced bark borders, wooden choice leaves and a vertical sap gauge.

The client review caught header and footer crowding, corrected in the final
layout. The selected arch, working machine pair and unlocked salvage rows
were checked in the disposable flat test world.

Build and 195 required GameTests passed. An earlier run failed the existing
horde-roll and microbiome pillar-spread tests. The unchanged rerun passed.
Evidence is kept separately in build/approved-art-final-verification.log and
build/approved-art-final-rerun.log.
