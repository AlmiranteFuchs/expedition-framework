# Bloom Canker — design proposal

Status: rejected visual exploration. The user did not like these concepts.
Do not treat the A/C recommendation below as an accepted direction. See
`research.md` for the subsequent reference study. Nothing here is implemented
or established origin lore.

The user identified the existing microbiome heart as too cubic and unconvincing
for the pale-and-amber influence. The current asset is a full cube with a six-face
translucent vein/glow shell. The proposal replaces the anatomical-heart reading
with a colony anchor that looks like infected host material gathering into a
split, hollow woody growth.

`concepts.png` is a built-in image-generation reference board, not a texture or
an in-game screenshot. `prompt.txt` contains the generation prompt.

- **A / Low Gall**: squat, asymmetric and grounded; easiest to connect visually
  to the approved flat infection material.
- **B / Split Knot**: a taller broken shell with a readable dark hollow; broad
  bark masses rather than fingers, antlers or an exposed organ.
- **C / Bark Seam**: a low rupture in the substrate; the least object-like form.

Recommended direction: A's low grounded mass with C's off-center split. Borrow
only enough of B's hollow to make the target readable. Final native textures
should read as directional bark tissue, not the rocky stepped surfaces of this
concept. Keep the model economical; the concept is not a license to add dozens
of small voxels. Use no metal, floating gemstone, literal eye or anatomical heart.

## Mechanical fit

The anchor keeps the existing colony ownership and stop-growth counterplay.
Its amber seam quietly signals activity. Dormancy keeps the same silhouette but
removes amber activity. Infection remains through contact and the approved
surface layer stays flat. No raised roots are added to surrounding terrain.

The current growth bootstrap assumes a sturdy cube and adds moves against the
heart's six faces. A non-cube implementation must seed valid nearby host surfaces
instead and retain the layer's existing sturdy-face support rule. Selection and
collision must match the actual model, rather than retaining an invisible cube.
The six-face aura must be replaced with a localized seam effect. Registry ids,
saved colony links and recipe references should remain compatible.

If this form is selected, update player-facing heart terminology, portable item
art, containment-machine specimens and journal diagrams together. The ordinary
essence/bootstrap chain, shared hive behavior and dimension liberation proof are
independent of the organ's physical shape and should retain their rules.
